# Rin 内部版激活指南（0.1.9）

> 适用 APK：`Rin_0.1.9_release.apk`（versionCode 10）
> 未激活 = 精简版（今日/课表/校务/我的，四个标签，无任何签到元素）；
> 激活后 = 完整版（新增「签到」标签 + 签到自动化 + 名单 + 全套功能）。

---

## 一、安装

1. 把 `Rin_0.1.9_release.apk` 传到手机安装（已用正式密钥签名，覆盖安装 debug 包可直接升级）。
2. 首次打开就是可用状态：本地模式直连学校，不需要注册。

---

## 二、激活通道 A：学号 + 姓名（推荐，全自动）

前提：管理员先把你加入白名单（见第四节）。

1. 打开 **我的 → 教务与数据**，填好「名单姓名」并保存。
2. 点 **「登录教务」**，在网页里完成教务登录（校外先登录 WebVPN，滑块需要人工完成）。
3. 登录成功后回到 Rin，App 会**静默**读取你的学号 + 姓名，向校验服务器核对白名单。
4. 白名单命中 → 自动进入完整版：底部多出「**签到**」标签，出现签到聊天卡与名单功能。全程无任何提示，也不需要你做别的。

注意：
- 校验有频率限制（每小时 8 次），失败多次会被暂时限制，等一小时即可。
- 登录成功但没激活？让管理员确认白名单里的「学号 + 姓名」与你教务里的完全一致（姓名以教务系统为准）。

---

## 三、激活通道 B：激活码（备用）

1. 打开 **我的 → 关于与隐私**。
2. **3 秒内连点版本号 7 次**，打开签到终端。
3. 在终端输入管理员发放的激活码，回车。
4. 校验通过即进入完整版。

---

## 四、管理员：维护白名单

### 方式 1：管理台（网页）

打开 `https://www.sykesp.com/rin-license/admin/`，用管理员口令登录，进入「**学生授权**」标签：

- 新增：填**学号 + 姓名**（姓名要与教务一致；保存后姓名不再回显）。
- 撤销：删除该条目即可。被撤销的设备重新激活会被拒绝，已激活设备也会在**每日核验**后自动降级回精简版。

### 方式 2：服务器（SSH）

```bash
ssh root@123.56.99.154
TOKEN=$(grep LICENSE_ADMIN_TOKEN /etc/rin-license/api.env | cut -d= -f2-)
# 新增
curl -s -X POST http://127.0.0.1:18083/api/admin/students \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"studentId":"25034480114","realName":"钟宇瀚","note":"备注"}'
# 查看列表
curl -s http://127.0.0.1:18083/api/admin/students -H "Authorization: Bearer $TOKEN"
```

## 五、激活之后：云端保底（强烈建议配置）

签到链路是**本地与云端并行竞速，谁先出结果用谁**。云端保底需要登录一次：

**我的 → 教务与数据 → 云端保底**：
- 服务地址：留空（默认 `https://signup.sky2333.top`）
- 账号 / 密码：填云端站点的账号密码
- 点「登录云端」，出现成功提示即可

配置后，自动签到与手动交接取码的链路变为：

```
本地直连学校 ──┐
              ├─ 谁先出签到码用谁
云端铸造/反代 ──┘
```

本地连不上学校（校外流量被拦、教务维护）时，云端自动接管，无需任何手动切换。

---

## 六、每日核验与撤销机制

- 已激活设备每 **24 小时**向校验服务器核对一次授权状态。
- 授权被撤销 → 设备自动降级回精简版（签到标签消失）。
- 重新授权后重新登录教务即可再次激活。

---

## 七、常见问题

| 现象 | 处理 |
| --- | --- |
| 登录教务成功但没激活 | 白名单学号/姓名与教务不一致；或触发限频（等 1 小时重试） |
| 激活后突然回到精简版 | 授权被撤销，或每日核验失败——联系管理员确认 |
| 校外登录教务卡住 | 先在 WebView 地址栏进 WebVPN 登录，再回 App |
| 云端保底登录失败 | 确认服务地址正确；部分流量网络会拦截未备案域名，换 Wi-Fi 或稍后重试 |
| 想暂时隐藏签到功能 | 我的 → 教务与数据 → 底部「完整版」开关，关掉即回精简版（随时可再开） |
