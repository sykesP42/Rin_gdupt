# Rin 0.1.9 更新说明

课表助手的一次大版本，聚焦三件事：看得更清楚、分享更好看、连接更稳。

## ✨ 新功能

- **课表三视图**：日 / 周 / 表自由切换，首页 Mini 卡片点「打开」直达对应视图
- **课表分享卡片**：一键生成图片分享，支持横排 / 竖排版式、水印与署名开关
- **云端保底**：可选登录云端服务，校内校外都能拿到最新课表数据，本地云端双通道自动取快的那条
- **每日数据核验**：账号状态异常时自动降级保护，恢复后自动同步

## 🔧 体验优化

- 教务登录支持校外 WebVPN，会话过期一键重连
- 头像 / 封面裁剪重做：拖动跟手、双指定点缩放
- 大量文案与界面细节打磨

## 🛡 隐私

- 教务账号密码只保存在你的手机本地，Rin 不会上传或发送
- 支持一键隐藏个人信息（真名 / 学号不再出现在界面与分享里）
